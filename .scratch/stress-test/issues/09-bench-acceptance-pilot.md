# 09: 台架驗收與前測

**What to build:** 研究人員依一份台架驗收清單確認兩支韌體在實機上行為正確，再以光耦與 RF 各跑一輪 40 筆、10 ms 間隔的前測，確認面板讀數流程順暢，三份 CSV 能在 Excel 中直接整理成第五章的表格。

**Blocked by:** 04, 06, 08

**Status:** needs-human（需接上硬體）

- [ ] 驗收清單文件：READY 內容、0 ms 間隔下 `T` 時間戳間距符合單筆動作時間、`ABORT` 於一筆內中止、光耦結束後腳位全為 LOW（LED 或三用電表）
- [ ] 兩支韌體逐項通過清單
- [ ] 光耦、RF 各完成一輪 40 筆／10 ms 前測，跑帶上不站人並錄面板影片
- [ ] CSV 以 Excel 開啟中文無亂碼，能整理出「光耦／RF × 間隔」的掉包表
- [ ] 記錄前測中發現需調整的參數（每段筆數、逾時、輪數）
