# 08: 介面易用性整理

**What to build:** 研究人員站在跑步機旁也能一眼看懂下一步：畫面分為上方狀態列（連線燈、入口、目前輪次與條件）、中央「現在要做的事」大卡片（單一主要按鈕或數字輸入框＋預期值）、右側條件矩陣與進度；字級放大、全繁體中文。

**Blocked by:** 06, 07

**Status:** ready-for-agent

- [ ] 三區版面在 1920×1080 與 1280×720 下都不重疊、不需捲動
- [ ] 任一狀態只有一個主要動作被強調；不可用的按鈕停用而非隱藏
- [ ] 緊急停止按鈕在所有狀態可見
- [ ] 所有提示、錯誤訊息為繁體中文
- [ ] 介面只呈現測試核心狀態與轉發輸入，不含判定邏輯
