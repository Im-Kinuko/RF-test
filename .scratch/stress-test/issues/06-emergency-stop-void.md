# 06: 緊急停止與作廢

**What to build:** 任何狀態下研究人員按空白鍵或大紅色「緊急停止」，系統立即要求 Arduino 中斷迴圈並送停止，該輪進入總結並標記為作廢；研究人員也能在一輪結束後手動作廢並填原因。作廢輪的原始資料保留但不計入矩陣進度。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 兩支韌體在 `RUN` 迴圈中以非阻塞方式檢查 `ABORT`，於一筆內中止並回 `ABORTED,<n_sent>`
- [ ] 光耦韌體在完成、中止、錯誤等所有結束路徑把所有腳位拉回 LOW
- [ ] Unity 緊急停止流程：送 `ABORT` → 送 `STOP` → 本輪總結（作廢）
- [ ] 一輪可標記作廢並填寫原因，寫入每輪 CSV
- [ ] EditMode 測試驗證：各狀態下緊急停止送出的指令與結束狀態、作廢不計入進度
